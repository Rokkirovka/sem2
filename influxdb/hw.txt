Зачем:
Фильтрует данные по времени — показывает только записи за последние 5 минут. Все наши данные попадают в этот интервал.

Команда:
curl.exe -G "http://localhost:8181/api/v3/query_sql" -H "Authorization: Bearer apiv3_ZpSc2ZQ74Bsqm7lds5zhcacEKRmPKQx0RjAHNPUVuGfHD-YxJzhwauqIQwFvyrY3czrQH_NcaHBTolDh5aWnrw" --data-urlencode "db=mydb" --data-urlencode "q=SELECT location, avg(value) AS avg_value FROM temperature GROUP BY location"

Результат:
[{"location":"room2","avg_value":22.0},{"location":"room1","avg_value":24.0}]

Зачем:
Группирует данные по тегу location и вычисляет среднее значение value для каждой комнаты:
- room1: (23 + 25) / 2 = 24
- room2: 22 (только одна точка, поэтому среднее = 22)
